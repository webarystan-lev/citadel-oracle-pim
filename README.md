# 🏛️ Citadel Oracle PIM (Personal Information Manager & Knowledge Hub)
> *«Се, Я полагаю в Сионе камень краеугольный, избранный, драгоценный...» (1 Петра 2:6)*

**Citadel Oracle PIM** — это суверенный цифровой органайзер, база знаний, зашифрованный сейф паролей и интеллектуальный оракул, созданный для **Льва Николаевича** (пастора, миссионера, руководителя «Миссии Шехина» и основателя веб-студии **Web Arystan**).

Система спроектирована специально для безопасной работы в интернете из любых миссионерских поездок и локаций, обеспечивая мгновенный доступ к знаниям, заметкам, дневникам и управлению проектами.

---

## 🌟 Ключевые Модули Системы

1. **💬 ИИ-Чат & Персональный Оракул**:
   * Мультипровайдерные диалоги в реальном времени с флагманскими моделями:
     * **Google Gemini** (`gemini-2.5-flash`, `gemini-1.5-pro`)
     * **Anthropic Claude** (`claude-sonnet-4-6`, `claude-opus-4-6`, `claude-haiku-4-5`)
     * **Mistral AI** (`mistral-large-latest`)
   * Прямая настройка параметров генерации (Temperature, Max Tokens, System Prompt) в боковой панели.
   * Обязательная подпись Ордена с указанием чина и назначения модели (**Shekinah Citadel Oracle Spirit**).
   * Скачивание истории диалога в структурированном Markdown.

2. **📖 Ежедневный Журнал (Journal with Gemini)**:
   * Запись повседневных мыслей, событий и духовных благословений.
   * Генерация ИИ-вопросов для вечерней и утренней рефлексии в 1 клик.
   * Автоматический ИИ-синтез и тегирование записей.

3. **📁 Управление Проектами (Project Hub)**:
   * Карточки проектов (*Миссия Шехина*, *Web Arystan*, *Citadel Cloud*, *AI Oracle PIM*).
   * Статусы (`Active`, `Planning`, `Completed`, `Archived`), категории, описание и этапные цели (Milestones).

4. **📝 Заметки & База Знаний**:
   * Категоризированные конспекты по теологии, программированию, служению и идеям в формате Markdown.

5. **🔐 Зашифрованный Сейф Паролей и Ключей (Vault)**:
   * Хранение API-ключей, токенов, SSH-ключей и паролей.
   * Сквозное шифрование по стандарту **AES-256 (Fernet)**. Содержимое в базу данных Convex DB передается строго в зашифрованном виде.
   * Переключатель `👁️` для мгновенной расшифровки секретов на лету.

6. **🛡️ Двухуровневая Авторизация**:
   * Вход по секретному мастер-паролю (`PIM_SECRET_KEY`).
   * Живая валидация ключа Google Gemini API через вызов `genai.list_models()`.

## 🛠️ Технологический Стек

* **Язык**: Python 3.11+
* **Интерфейс**: Streamlit 1.58.0 (кастомизированный темный минимализм Цитадели)
* **СУБД и Облако**: [Convex DB](https://www.convex.dev/) (`convex==0.7.0` Python client + JS Convex 1.42.1)
* **Безопасность**: `cryptography==42.0.8` (AES-256 Fernet + SHA-256)
* **ИИ-Провайдеры**:
  * `google-genai` / `google-generativeai==0.8.6`
  * `anthropic==0.116.0`
  * `mistralai==2.5.2`
* **Окружение & Платформа**: Linux, Fish-Shell, Kitty Terminal, `direnv`, **Antigravity 2.0 & IDE**

## 🚀 Быстрый Запуск

### 1. Клонирование и активация
```bash
git clone https://github.com/webarystan-lev/citadel-oracle-pim.git
cd citadel-oracle-pim
direnv allow
```

### 2. Настройка секретов `.env`
Создайте `.env` в корне проекта:
```env
GEMINI_API_KEY=ваш_ключ_google_gemini
ANTHROPIC_API_KEY=ваш_ключ_anthropic
MISTRAL_API_KEY=ваш_ключ_mistral
CONVEX_URL=https://your-app.convex.cloud
PIM_SECRET_KEY=ваш_секретный_пароль_входа
```

### 3. Запуск веб-портала
```bash
streamlit run app.py
```

Проект включает конфигурацию agentic AI платформы **Antigravity 2.0**:

Это позволяет агентам Antigravity 2.0 взаимодействовать с бэкендом Convex DB, управлять заметками, анализировать дневники и поддерживать автотесты непосредственно из Antigravity IDE.
