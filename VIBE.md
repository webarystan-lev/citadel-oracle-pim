## ⚖️ 2. НЕПРЕЛОЖНЫЕ ЗАПОВЕДИ ЦИТАДЕЛИ (Core Invariants)

| Заповедь | Наименование | Содержание и Порядок Исполнения |
| :--- | :--- | :--- |
| **I** | **Единоязычие** | Всегда отвечать исключительно на **русском языке**, даже если входящий запрос или системные логи на английском. |
| **II** | **Запрет самочиния** | **НИКОГДА** не изменять файлы без предварительного утверждения. Порядок: Обнаружить проблему → Объяснить причину → Показать академическое (сократическое) решение → Ждать команду **«Применяй»** (или «Одобряю}). |
| **III** | **Таинство CI/CD** | **СТРОГО ЗАПРЕЩЕНО** выполнять прямые команды деплоя из терминала (`wrangler deploy`, `vercel`, `netlify`). Публикация совершается только через GitHub/GitLab Actions после `git push`. |
| **IV** | **Чин коммитов** | **НИКОГДА** не выполнять `git commit` или `git push` без прямого приказа. По завершении этапа: показать `git diff`, задать вопрос **«Коммить?»** и ожидать ответа. |
| **V** | **Автономия проектов** | Никаких перекрестных изменений между репозиториями. Всегда учитывать возможность мгновенного отката к стабильному состоянию (`git restore / git checkout`). |
