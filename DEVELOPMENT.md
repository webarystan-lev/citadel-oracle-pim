### Управление записями и календарь

Журнал, заметки, проекты, задачи и метаданные записей Сейфа редактируются в полноширинных формах. Предпросмотр Markdown отображается под полями, а проект и начало/окончание временной шкалы можно настроить в одной форме. Секреты Сейфа никогда не попадают в Markdown-предпросмотр; при редактировании пустое поле секрета сохраняет прежнее зашифрованное значение.

Календарь группирует записи по разделам, выделяет дни создания и дни внутри назначенной временной шкалы, позволяет просматривать, редактировать и удалять записи, а также создавать записи выбранного типа для выбранной даты. Операции проходят через внутренние Convex-функции и bearer-защищённый `/pim`; схема использует необязательные даты, поэтому существующие документы остаются совместимыми.

## 🔐 Шифрование и Безопасность (Security Service)

Модуль `providers/security.py` отвечает за два уровня защиты:
1. **`verify_gemini_api_key(api_key)`**: Выполняет официальный вызов `genai.list_models()` к Google Gemini API для валидации ключа при входе в систему Gatekeeper.
2. **`encrypt_secret(plain_text, passphrase)` & `decrypt_secret(encrypted_text, passphrase)`**: Использует случайную соль и PBKDF2-HMAC-SHA256 для получения ключа Fernet. Старый формат на SHA-256 остаётся доступен для чтения, чтобы не потерять существующие записи Сейфа.
3. **Защита Convex:** все запросы к БД проходят через HTTP endpoint `/pim` с `CONVEX_API_SECRET`; сами Convex-функции объявлены внутренними. Один и тот же токен задаётся в окружении приложения и в переменных окружения выбранного Convex deployment. Без обоих параметров облачное хранилище отключено.

## 📖 Мульти-Журнальная Архитектура (Multi-Journal System)

В модуле `📖 Журнал` реализована концепция тематических журналов (*Journal with Gemini*):
1. **Таблица `notebooks` в Convex DB**: Хранит категории/блокноты (`title`, `description`, `icon`, `categoryType`).
2. **Таблица `journals` в Convex DB**: Связана с `notebooks` через новое поле `notebookId` и индекс `by_notebookId`.
3. **Узкопрофильные ИИ-вопросы**: Каждая категория (`AI_WEBDEV`, `MISSION`, `SCHOOL_OF_CHRIST`, `FAMILY`, `THEOLOGY`, `GENERAL`) загружает доменные шаблонные вопросы.
4. **Сквозной ИИ-Синтез**: Поддерживается сканирование и рефлексия как одной записи, так и всех записей выбранного журнала во всю ширину экрана.

## 🗄️ База Данных Convex DB

Схема базы зафиксирована в `convex/schema.ts`:
* `chats` — Таблица настроек диалогов
* `messages` — История сообщений
* `notebooks` — Тематические журналы/блокноты
* `journals` — Ежедневные записи журналов с привязкой к `notebookId` и `projectId`
* `projects` — Проекты, категории и milestones
* `notes` — База знаний и заметки
* `vault` — Зашифрованные записи сейфа

Для применения новой схемы в облаке Convex выполняйте:
```bash
npx convex dev --once   # Для среды разработки
npx convex deploy       # Для боевой среды (Production)
```

> **Безопасность доступа:** Python SDK Convex не используется. Streamlit выполняет серверный запрос к `/pim` с секретом в заголовке `Authorization`; секрет никогда не передаётся в браузер. Безопасный порядок настройки и переключения deployment приведён в [README.md](./README.md).
